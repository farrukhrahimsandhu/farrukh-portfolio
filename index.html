My Case Studies

1. Search Intelligence Data Contract (DuckDB & Hugging Face)

The Problem: Querying massive Parquet files locally takes too much time and storage.

The Action: Built a data contract using DuckDB's HTTPFS extension to securely query millions of rows of search console data directly from a Hugging Face warehouse.

The Result: Achieved instant data exploration without downloading gigabytes of CSVs, successfully setting the grain for future ML prediction models.

2. Predicting Traffic Drops (Baseline Action Scores)

The Problem: We needed a way to flag underperforming web content before applying complex ML models.

The Action: Designed a baseline rule filtering for high opportunity (Search Volume > 500) and poor performance (CTR < 2%). Handled data leakage by removing future-window metrics.

The Result: Exported a prioritized queue of actionable targets. This baseline now serves as the honest benchmark my future ML models must beat.

3. Agentic Automation Pipeline

The Problem: Manually drafting and formatting technical updates is time-consuming.

The Action: Built a no-code 3-step pipeline (Draft ➡️ Critique ➡️ Revise) utilizing prompt engineering to automatically format raw notes into professional case studies.

The Result: Reduced writing time from 25 minutes to 3 minutes per post, saving over an hour of manual labor across 5 runs.
